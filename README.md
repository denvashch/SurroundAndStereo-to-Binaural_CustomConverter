"48K_24bit/" folder contains KU100 HRTFs measured at the University of York. In this project, they serve solely as temporary placeholders for converter algorithm testing.

"Source/" folder contains arbitrary mono and stereo channel recordings for comparative analysis.

"Code" contains Python code for stereo/surround to binaural conversion algorithm (see the last section "combinedbinauralprocessor"). Omni mic IR and compensation filtering options are yet to be added.
